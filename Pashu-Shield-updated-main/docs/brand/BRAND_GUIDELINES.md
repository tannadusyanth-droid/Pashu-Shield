# Pashu Mitra — Brand guidelines

Designed to conform to DBIM 3.0 and GIGW 3.0; CQW/STQC certification pending audit.
Independent initiative; not an official Government of India website (`OFFICIAL_GOV_PORTAL=false`).

## Mark (concept C, chosen by the owner on 07/10/2026)
A solid shield with the horns of cattle forming an **M** and a small sun, cut out of the shield (evenodd), so one file works in black on white and white on dark. Original artwork: no State Emblem, Ashoka Chakra, tricolour or any official logo is used or imitated.

## Lockup 3B (DBIM 5.2.4)
Mark plus organisation name in a single language, no emblem. English "Pashu Mitra" and Hindi "पशु मित्र" masters use the same name size (27 units), the same 16-unit gap and the same vertical centring. Tagline is optional and currently **not** drawn (placeholder `[Tagline]` in PLACEHOLDERS.md). Regional masters (Marathi, Telugu …) are added to `NAMES` in `scripts/build_logos.py`; until then those languages show the English lockup.

## Colour (DBIM 5.3, Checklist item 22)
Black `#000000` on white in the header; white `#FFFFFF` on key colour `#0F5757` in the footer. Social card and splash use the key colour only. No other variants.

## Geometry (RTI "Guidelines for Logo", geometry only; nothing else borrowed)
- Mark box 50 × 58 units. Clear space unit **X = 2 horn-stem widths = 12 units**, on every side.
- Minimum: horizontal lockup 57 px high; mark 30 px. Vertical lockup uses the same minimum mark height (57 px). Below the minimum, `logo.js` switches to the mark.
- Forbidden: stretching, condensing, rotation, outline, hollow, drop shadow, bevel/emboss, glow, texture, gradient, redrawing, colour on the header.

## Files (`frontend/assets/brand/`)
`pashumitra_<standard|alternate|mark>_<eng|hin|xxx>_<black|white>.svg` (10 masters, each ≈ 0.6–4 KB, limit 100 KB), `favicon.svg`, `../../favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-192/512.png`, `social-1200x630.png`. Wordmarks are outlined paths. Everything is generated by `python3 scripts/build_logos.py`; do not hand-edit.

## Use
`PMLogo.html({ variant: "horizontal|vertical|mark", tone, lang, height, context: "header|footer|page" })` in `frontend/logo.js`. It locks the aspect ratio, applies clear space, clamps sizes, forces black in the header and white in the footer, and accepts no style, class, filter or transform. The link wrapper's accessible name is "Pashu Mitra – Home" (`PMLogo.link`).

## Co-branding (DBIM 5.4)
At most 2 co-brand logos in the header, only logos the owner supplies and is authorised to use. Pashu Mitra stays on the left (horizontal) or on top (vertical); each logo keeps its own clear space. None are included yet.

## Enforcement
`frontend/tests/logo_rules.test.mjs` fails the build if a logo file exceeds 100 KB, is not single-colour outlines, is rendered below minimum size, is rendered outside `PMLogo`, has CSS filters/transforms/shadows, or is coloured in the header.

## Known gaps
1. **Interim wordmark fonts.** Outlines use Liberation Sans Bold (Latin) and FreeSans Bold (Devanagari, hand-shaped: ि reordering, GSUB ligatures, GPOS mark attachment). Re-run the build with `NOTO_LATIN_BOLD` and `NOTO_DEVA_BOLD` pointing at Noto Sans Bold files to match DBIM 4 before release, then re-check the Hindi outline by eye.
2. Hindi at the same size looks slightly smaller than Latin; this follows DBIM's "identical relative size" rule.
3. Rendering was checked with a custom rasteriser, not in browsers.
4. No toolkit icon set or official logo has been supplied.
